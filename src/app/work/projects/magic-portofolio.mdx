## Overview

Website portofolio pribadi untuk memperkenalkan profil, pengalaman, dan karya Dimas Achyar Trizyaputra. Dibangun menggunakan Next.js dan Once UI, situs ini menyajikan proyek dalam bentuk halaman detail bergambar serta menyediakan ruang terpisah untuk artikel, pencapaian, dan pelatihan.

Konten proyek dan artikel dikelola menggunakan MDX, sehingga setiap halaman dapat menyertakan teks, metadata, dan gambar. Navigasi multi-halaman membantu pengunjung menjelajahi informasi secara terstruktur, baik dari halaman profil maupun dari daftar karya.

## Key Features

- **Profil dan Tentang**: Menampilkan ringkasan profil serta informasi latar belakang.
- **Daftar Proyek**: Menyajikan karya dalam daftar visual dengan halaman detail dan galeri gambar.
- **Blog Berbasis MDX**: Memuat artikel teknis dengan halaman khusus untuk setiap tulisan.
- **Pencapaian dan Pelatihan**: Mengelompokkan informasi pencapaian dan kegiatan pelatihan.
- **SEO dan Berbagi Konten**: Menyediakan metadata halaman, dukungan Open Graph, dan RSS feed.
- **Tampilan Responsif**: Menyesuaikan layout untuk berbagai ukuran layar.

## Technologies Used

- **Next.js**: Framework untuk routing dan rendering halaman website.
- **React dan TypeScript**: Digunakan untuk membangun antarmuka dan komponen dengan tipe yang terdefinisi.
- **Once UI**: Sistem komponen dan gaya visual yang digunakan pada antarmuka.
- **MDX**: Format konten untuk artikel blog dan detail proyek.
- **Sass**: Digunakan untuk styling komponen dan halaman.

## Challenges and Learnings

Tantangan dalam membangun portofolio ini adalah menyusun beragam informasi agar tetap mudah dijelajahi tanpa membuat halaman terasa padat. Konten proyek dan artikel juga perlu konsisten, sementara tiap halaman tetap memiliki gambar dan metadata yang sesuai. Penggunaan MDX membantu menjaga konten tetap terstruktur, sedangkan komponen Once UI mendukung tampilan yang konsisten di seluruh situs.

## Outcome

Website ini menjadi pusat informasi profesional yang menggabungkan profil, proyek, tulisan, pencapaian, dan pelatihan dalam satu tempat. Pengunjung dapat melihat ringkasan karya melalui daftar proyek, lalu membuka halaman detail untuk memahami konteks dan melihat dokumentasi visualnya.
